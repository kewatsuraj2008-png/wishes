# Birthday Wishes Website

Static birthday surprise site for GitHub Pages.

## What it includes

- A polished landing page with a centered birthday cake
- Animated firecrackers around the cake
- A surprise button that opens a second page
- A wishes page with the candles turned off and heartfelt messages

## Deploying

This repo includes a GitHub Pages workflow in `.github/workflows/deploy.yml`.

To make it live on GitHub:

1. Push `main` to GitHub.
2. In repo settings, enable GitHub Pages using `GitHub Actions` as the source.
3. After the workflow runs, GitHub will provide the live URL.
